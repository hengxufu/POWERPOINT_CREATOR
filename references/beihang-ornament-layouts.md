# 北航模板的配饰语法与单元素库

用户要求学习模板配饰方式与布局并尝试网页生成。使用本文件时先读beihang-theme.md与web-single-element.md。校级身份层固定，配饰是次级视觉层；通用机翼、卫星或银杏叶都不能代替真实校徽校名。

## 本地观察的范围

进一步分析4套模板各第2/3/5/8/12页，共20页，对象坐标、组内变换及源图片形成分析图；不是完整PowerPoint渲染，字体、裁切、蒙版、阴影不保证复现。现有模板也发现部分图片关系缺失，不能把分析图中的空框当成实际装饰。记录位于项目validation/beihang-template-study/layouts/object-layouts.json，不上传模板全文。

| 来源页 | 可学习的布局语法 | 科研汇报中的转化 |
|---|---|---|
| 蓝色工作汇报第2/3页 | 错位层叠编号牌、左右交错的信息组 | 原生章节号/标题与局部配饰错位，保持同一基线，不生成整张内容牌 |
| 蓝色工作汇报第8/12页 | 图标和解读成组、章节的大留白 | 小图标帮助识别解释项；章节配饰缩为次焦点，不铺满背景 |
| 绿色第2/8/12页 | 左侧锚点与编号列表、左图右解读、同尺度多组证据 | 锚点复用但正文构图变化，比较页先统一证据尺寸 |
| 黄色第3/5/8页 | 大编号与小几何的尺度差、错位几何重复节奏 | 用一个独立主体呼应原生编号；简单框/几何仍原生，不套用满页边条 |
| 立体蓝第3/8/12页 | 半幅主视觉与内容区分工、图和解读对齐 | 仅一个精致立体主体；图表、说明、连接线保持原生 |

学习主次尺度、留白、锚点、对齐与重复节奏，而不是盲目复刻模板边框或所有页套三卡片。封面/章节/结尾可用较明显配饰，结果页让装饰退到最弱层；新增每个配饰要有实际用途，不能按数量判美观。40元素规则仍按独立可见对象核对，不用复制装饰凑数。

## 先3个样本，再推广

`scripts/ornament_library.py`提供12个本地提案与6类局部组合配方（cover/section/method/result/comparison/closing）。默认仅准备钛蓝机翼曲面、开口轨道弧、半透明镜头环3个单主体样本。提案来源明确标codex_local_proposals，不是GPT网页回复或成图。推荐框以13.333×7.5为基准，换画布必须缩放；避开右上身份与底部页脚，按实际内容微调。

```powershell
python scripts/ornament_library.py --out <workspace>/asset-jobs/ornaments-v1
# 只有需要全部独立任务时才显式传入更多--ids，不自动耗用12次图像额度。
```

本地脚本只准备。先实际向网页版发送观察摘要，请网页审查/改进设计系统、6种配方及12个独立主体，保存真实回复后筛选；若通道失败，本地提案不冒充网页规划。发送状态不明则记录submission_unknown并回原会话检查，不在新对话重新发送。

每张图单独提交、原图下载、alpha与分辨率检查，再查看实际图像。比较柔和高光、材质统一、完整轮廓、缩小后的辨识度、浅/深背景边缘。适用参数不是保证结果。模型可见性不足时，只按当次用户实际允许的范围使用，明确型号未核实；聊天菜单High不等于GPT-6，创建图像不等于Image2.5。

样本满意再扩充同一系列；不混用厚塑料、玻璃、线描、写实四种风格。原生线条、简单几何和连接线不交给图像模型；复杂工业曲面、玻璃折射等局部材质主体才适合生成。每个样本保持一张原图对应一个独立picture，不拼图后裁切。实际放入研究PPT后再做代表页与全篇审查，不把配饰库单图审查当成整份PPT视觉验收。
