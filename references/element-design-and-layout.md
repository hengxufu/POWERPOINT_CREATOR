# 单元素设计与页面排版精修

用于视觉重设计、布局美化和元素库扩充；局部改字只检查受影响区域。北航身份层沿用beihang-theme，不重新生成。新规划自动附带本文件对应的设计合同；旧规划可增量补字段，不必重发网页任务。

## 先设计关系，再选择外观

先用一句话确定该页要让观众看懂的关系，再选layout_catalog中合适的起点。给主证据最大的可读空间，次证据形成支持而不是另起一个焦点；每个元素都要说明它帮助定位、比较、解释还是导航。删去没有用途的装饰，不用缩小文字换取“丰富”。

| 内容关系 | 组织方式 | 精修重点 |
|---|---|---|
| 整体—局部 | 主证据与源图局部放大并列 | 放大框和真实区域对应，注释靠近被解释处 |
| 方法—条件 | 原生流程/层级 + 条件说明带 | 分组底板、节点与连线分层，避免交叉箭头 |
| 并列比较 | 同尺度图、共享对齐线与图例 | 单位、坐标范围与条件一致；差异用标注指出 |
| 公式—解释 | 公式主区 + 符号/单位区 + 物理结论 | 推导按步骤展开，标明假设、适用范围，不省略定义 |
| 证据—边界 | 证据主区 + 解释与局限 | 先保证误差条、坐标和引用可读，装饰退后 |

## 一套设计令牌，允许不同构图

design_system记录背景、文字/强调/边界颜色、字号角色、间距、线宽、圆角、图像材质和光源。13.333×7.5画布可从.08/.16/.24/.40英寸间距、28–36pt标题、18–24pt正文、12–14pt来源开始；都是可调整起点，不是强制审美公式。文字自然换行后再校正对齐；不要靠连续空格对齐或水平拉伸文字。

将40个以上的独立可见对象组织成少量视觉组：标题/论点、证据、解释、来源与身份。组内紧、组间松；元素计数仍由实际PPTX审计，不能把一段话拆成40个文本框或把表格单元格算独立对象。封面/章节页若密度要求与留白冲突，记录具体冲突、调整有意义的可编辑信息层，不以随机装饰填数。

正文页优先稳定外边距和内容基线，身份预留区不参与正文排版。比较页可连续相同布局以保持同口径，但需layout_repeat_reason；不能为了“版式多样”破坏可比性。

## 单元素的精致度合同

每条请求visual_context除背景/材质/光照/摆放/避免项，还给viewpoint、silhouette、edge_treatment、detail_level、optical_padding。例如：三分之四视角、完整单一薄翼轮廓、克制倒角无光晕、目标摆放尺寸下仅保留可辨识细节、约10%原图留白。目标是单主体与最终缩放匹配，不把精细纹理当价值。

一套图标保持相同视角、笔画/厚度、光源、色彩角色；简单图标和几何优先原生矢量，复杂曲面或材质主体才生成。先审3个样本；放大检查边缘与材质，再按目标页面尺寸缩小检查轮廓和对比，最后在真实背景试放。原图alpha留白不同会造成视觉大小不同：允许在源代码中调整picture框和光学位置，但不得拉伸、重画品牌或未经记录改动证据图。

内容页装饰包围盒总面积12%是预警起点而非合格线；透明空白会高估占比。封面/章节允许大主体，但每页必须以实际渲染判断。审查记录写具体对象、问题与修改，不能只写“高级”。

## 可执行预检

每个content_block与实际摆放asset_request声明object_id、role、box_inches；文本声明font_pt。role为primary/secondary/annotation/ornament/container/background/theme。parent_id仅指向真正包住它的container；有意叠放逐对写allowed_overlaps=[{object_id,reason}]。alignment_groups=[{axis,members}]核对声明的对齐；reading_order列原生解释与证据的阅读顺序，不含配饰。

```powershell
python scripts/design_layout.py --plan <planning/deck_plan.json> --out <qa/layout-plan-v1.json>
```

预检发现越界、非法尺寸、重复ID、身份碰撞、容器关系和对齐声明错误时返回非零；遮挡、较小字号、连续重复布局和装饰占比是待人工判断的警告。旧规划缺role/font/reading_order时给补字段建议，不静默补出审查证据。此工具只读规划，不改PPT、不自动移动对象、不生成图片、不计实际40对象，也不签发美观通过。

修复顺序：证据/事实→身份与越界→遮挡→文字可读性→对齐与间距→材质与装饰。再渲染封面、技术页、密集结果页；逐页检查真实换行、裁切、公式、图例与来源。字体、主题、元素密度和delivery_gate继续独立执行，几何预检不能替代任何现有验收。
