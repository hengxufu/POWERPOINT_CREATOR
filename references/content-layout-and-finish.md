# 内容排版与美术精修

用于内容拥挤、版面单调、图文脱节和素材融合不足的修订。沿用全篇设计与代表页流程；以下是可调整的设计决策，不是固定字数、固定比例或自动美观标准。

## 将论证组织到页面

先写清这一页的问题或结论，再分配空间。标题可以是待验证的问题，不能为了有力而将推测改写成确定结论。正文保留证据、解释和影响结论的条件；完整推导、补充细节进入讲稿或后续页，但单位、样本量、不确定性及来源不能在精简时丢失。

| 页面问题 | 优先修订 | 真实渲染时检查 |
|---|---|---|
| 全页都是长段落 | 按论点—证据—解释分组，删重复表达；内容仍过量则拆成递进页 | 保留科学限定，避免孤立末行和挤压来源 |
| 图大但观众看不懂 | 保留主图，增加原生局部放大、对应注释及一句解释 | 放大区域可回查；注释与证据位置关系明确 |
| 多图尺寸小、重点相等 | 一张主证据配次证据，或分概览页和关键证据页 | 坐标、图例和误差条在目标阅读尺寸可辨 |
| 比较页视觉不公平 | 匹配尺度、基线、条件和图例，差异用原生标注解释 | 不通过裁图、换轴范围或透视夸大差异 |
| 方法流程交叉混乱 | 主流程保持单一方向，条件放侧带；复杂分支另页展开 | 箭头落在正确节点，输入/输出与验证标准清楚 |
| 封面精美但正文松散 | 将封面的颜色、字体、线条规则带入正文，按证据改变构图 | 不把封面大配饰机械复制到密集结果页 |

短标题与解释句尽量自然换行，不靠连续空格排版。中文标点、英文长词、上下标、列表缩进和混合字体需在真实渲染中检查。存在长英文术语时可用合理换行或注释解释，不能压扁文字。保留微软雅黑与Times New Roman的既有字体要求。

## 将拥挤问题变成具体修订

`design_layout.py`对普通文本提供`text_pressure`警告：以中西文字符宽度、声明字号、文本框净尺寸、显式换行和段后距粗估容量。默认内边距每侧.08英寸、行距倍率1.2、段后4pt；实际源文件参数优先，用`text_layout`明确声明。

```json
{
  "object_id":"explanation",
  "role":"secondary",
  "text":"保留条件的具体解释句。",
  "font_pt":21,
  "box_inches":[9.1,1.9,3.5,3.2],
  "text_layout":{"margin_inches":[0.08,0.08,0.08,0.08],"line_spacing":1.2,"paragraph_space_after_pt":4}
}
```

统一左缩进用`text_layout.indent_pt`声明，默认0，单位为点；估算从每行净宽中扣除。必须与原生文本框设置保持一致，不能通过少报缩进消除警告。

这是估算，不使用真实字形、英文单词断行、复杂悬挂缩进或PowerPoint排版引擎。它不测量图表/表格/公式内部文字，不输出“已适配”，也不自动缩字号或改写正文。警告后先检查原生文本框实际参数，再调整分组、解释区宽度或页数，最后渲染复查；没有警告同样不保证不溢出。

页面可声明`spacing_groups=[{axis:"horizontal",members:["figure","explanation"],min_gap_inches:0.3}]`，成员按实际空间顺序排列；vertical用于上下关系。最小间距由内容决定，组内应紧于组间，不能全篇平均分配。间距不足只提醒；无效对象引用需要修复。

图注或解释块用`caption_for:"figure"`关联证据对象。边框之间距离超过.6英寸会提醒检查视觉关联；这只是本技能的预警起点。远距离注释若确有必要，用清楚的原生引线并实际查看，不靠填豁免字段证明合理。注释不一定放在图下方，但应能明确对应具体证据。

## 美术精修顺序

先核对全篇内容递进：`depends_on`列出本页理解所需的前置页面ID，无依赖则空数组。缺失ID、尚未讲解的依赖会进入内容修订任务；有意先结论后推导须用`nonlinear_reason`说明。相同`takeaway`的页面应增加真实证据、解释或边界；有意总结回顾用`content_repeat_reason`说明。检测仅忽略空白后比较文本，不能判断语义重复或科学推理是否成立，填写理由也不等于审查通过。

生成素材的`aspect`与`box_inches`共同决定摆放。宽高比差异超过1.8倍提示检查：优先等比留白、修改框或重新构图，阈值只是预警起点。透明留白可能让实际主体与外框不同，须看真实轮廓；不拉伸主体，不裁掉科学证据。`native_or_source`不接受生成素材的风格一致性要求，保留来源图的真实性。

先解决焦点、内容分组和真实可读性，再统一线宽、圆角、颜色、阴影与素材轮廓。底板负责组织信息，不给每个对象套卡片；分割线尽量轻，强调色只承担明确的信息角色。字号和线宽按角色分层，避免多个近似值产生无意差异。

单素材放大检查透明边缘，再按最终摆放大小检查轮廓，最后放回真实背景看融合。比较同系列主体可见轮廓的大小，不能只对齐不同alpha留白的PNG外框。检查白边/暗边、阴影截断、光源方向、落地接触和主次对比；必要修订创建新素材版本，原图与记录保留。

结果页优先保证真实证据的可读性。对科学图不添加虚构景深、立体透视或颜色处理；对品牌不重画变形。装饰可以简化，40个对象仍由有意义的原生说明、结构和真实内容承担，不能靠重复配饰补数。

代表页观察应记录具体问题和改动，例如“解释区末行拥挤，扩大宽度并将第二个论点移到下一页”，而非“更高级”。最终按[分阶段审查](art-direction-and-staged-review.md)查看实际页面，并保留仍未解决的事项。
