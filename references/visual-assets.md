# 单元素与页面美观

先成立原生排版、标题和证据，再决定是否需要装饰。封面可使用一件精致装饰，研究背景可使用概念对象；结果页优先真实证据。不按装饰数量评价美观。

从实际页面提取背景色、2–3 个主/辅色、光源方向、材质和目标位置，写入任务 visual_context。不同资产保持光照和材质一致；不要让模型顺带生成整页。

验收单主体、完整性、准确艺术字、真实 alpha；在深/浅背景检查白边、光晕和锯齿。alpha 主体包围盒只能辅助判断大小，不能识别多主体或科学语义。大画布中心的小主体可能在 PPT 中过小。

使用 `asset_job.py placement --job <目录> --box 8.5 1.5 3.7 4.5 --canvas 13.333 7.5 --min-ppi 180` 计算保持比例的放置框和有效分辨率。默认 contain，不拉伸、不修改原图、不自动裁掉主体或阴影。180 ppi 是可调建议，按实际放映环境复核。

placement.json 是跨引擎适配清单，不是所有制作引擎能直接读取的输入。Codex 按实际 renderer API 更新 asset_plan/outline/源文件，插入独立原生 picture，保留原生标题正文和旧素材版本。位图本身不等同于可编辑文本或矢量。

重建后运行 event integrated 并传 --pptx：脚本核对唯一对象名 slide_id/object_id 和图像哈希。只有素材实际存在于 PPTX 才能登记已接入；结构证明仍不代表视觉通过。

代表页原稿与修改稿比较：焦点、层级、留白、文字可读、证据可读、资产融合。装饰不覆盖坐标、图例、统计条件和来源。不在无真实渲染时声称美观提升已验证。
